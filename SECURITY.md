# Security

This repository is a teaching project. Break mode deliberately switches security
checks off so you can watch the attack each pattern stops. It only works when
`DEMO_MODE=1` is set, and the app refuses to start otherwise.

- Run break mode on your own machine only, bound to `127.0.0.1`.
- All data, codes and secrets in this repo are fake.
- Found a real vulnerability in the secure mode? Please open a private security
  advisory on this repository rather than a public issue.
